# Stack: React/Vite + Quarkus/LangChain4j + Postgres + SSE, deployed as one Compose stack on a persistent droplet

Building solo in ~30-36 hours, with Java as the developer's strongest language, we chose: React (Vite) frontend; a Java backend on Quarkus with the `quarkus-langchain4j` extension for the pluggable creative-assistant LLM call (mock-first default, no API key needed to demo, matching the spec's requirement directly); Postgres via Hibernate ORM/Panache with Flyway migrations; Server-Sent Events carrying both live dashboard updates and the server-authoritative simulation clock, so every role view and the split-screen demo mode stay in lock-step even at 60x speed instead of risking client-side drift. The whole stack is containerized as a single `docker compose` definition and deployed identically onto a persistent DigitalOcean droplet rather than a sleep-on-idle PaaS tier, so the required reviewable playground URL can't go cold mid-demo.

This qualifies for an ADR: it's hard to reverse (touches every layer of the build), surprising without context (Java/Quarkus is a less typical choice than the Node/Python stacks common for this kind of demo-heavy web app, and deserves the justification the spec's README explicitly asks for), and the result of a real trade-off (the developer's existing Java depth vs. a more "default" lighter-weight stack).

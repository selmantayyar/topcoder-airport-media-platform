# 09 — Retailer campaign builder + creative library + promo codes + history

**What to build:** A retailer can build a campaign (creative, audience rules, placement, schedule, budget), see a live audience-match preview, reuse creatives, generate time-boxed promo codes with a share-to-family option, and review past campaigns with a one-click "run again."

**Blocked by:** 07 — Passenger Screen simulator + QR claim flow, 06 — Decision pipeline + Gate 42 worked example

**Status:** ready-for-agent

- [ ] Campaign builder lets a retailer pick a creative, target zones/screens, set audience rules (destination, domestic/international, dwell time, delay), set a schedule and budget, and preview on a mock screen
- [ ] A campaign saved here is picked up by ticket 06's decision pipeline on its next run
- [ ] Live audience-match preview shows an estimated match percentage and expected impressions/redemptions while building the campaign
- [ ] Creative library supports reuse and one-click duplication of a past campaign
- [ ] Promo codes are time-boxed, expire when the linked flight's boarding closes, and support generating a second shareable code for family
- [ ] Campaign history lists past campaigns with spend, impressions, redemptions, and ROI, with a working "run again" action
